#1 codex-plugin-cc · AI代码审查插件工具
这是一个将 OpenAI Codex 能力集成到 Claude Code 环境中的插件，允许开发者在 Claude Code 工作流内直接调用 Codex 进行代码审查或任务委托，实现两大 AI 编程助手的协同使用。它打破了单一 AI 工具的边界，让开发者可以根据场景灵活切换和组合不同模型的优势，极大提升编程效率。该项目处于 AI 编程辅助与 IDE 插件集成赛道，代表了多 AI Agent 协作的前沿探索方向，值得关注。
#2 Zackriya-Solutions · AI会议助手本地化处理
一款基于 Rust 构建的本地优先 AI 会议助手，支持实时语音转文字（Parakeet/Whisper 加速4倍）、说话人识别及 Ollama 本地大模型摘要，全程 100% 本地处理，零云端依赖，完美保护会议隐私。对于企业和个人用户而言，既解决了敏感会议内容泄露的合规风险，又提供了媲美商业产品的智能笔记体验。该项目处于 **本地化 AI 生产力工具** 赛道，是自托管 AI 应用快速崛起趋势下的典型代表。
#3 strix · AI安全渗透测试工具
开源AI驱动的渗透测试工具，能够自动化发现并修复应用程序中的安全漏洞，适用于开发团队在上线前进行安全评估和红队测试场景。将AI能力与安全审计深度结合，大幅降低了专业渗透测试的门槛，让中小团队也能获得企业级安全检测能力。该项目处于AI安全工具（AI for Security）赛道的核心位置，是当前最热门的方向之一。
#4 JuliusBrussee · 提示词压缩优化
这是一个专为 Claude Code 设计的提示词优化技巧，通过"穴居人说话风格"（极度精简语法）将 Token 消耗降低 65%，在 AI 编程助手日益普及、API 成本备受关注的背景下，提供了一种低成本、高实用价值的 Prompt 工程方案。单日新增 926 星的爆发式增长说明开发者对降低 AI 使用成本有强烈需求，值得关注其背后的 Token 压缩方法论。所在赛道为 **Prompt Engineering / AI 成本优化**。
#5 asgeirtj · AI系统提示词泄露收集
该项目持续收集并公开各大AI厂商（Anthropic、OpenAI、Google、xAI等）旗下模型的系统提示词泄露内容，涵盖Claude、GPT、Gemini、Grok等主流产品，为研究人员和开发者提供了难得的"黑盒窥视"视角。通过分析这些系统提示词，可以深入理解顶级AI产品的行为边界设计、安全护栏机制和产品策略，对逆向工程AI产品设计极具参考价值。该项目处于AI安全与提示工程赛道，在大模型高速迭代的当下，凭借持续更新和覆盖广度，短期内引发大量关注。

#1 msitarzewski · AI Agent框架

#2 strix · AI安全渗透测试工具

#3 codebase-memory-mcp · 代码库智能索引MCP服务
这是一个高性能的代码库智能 MCP 服务器，能将代码仓库索引为持久化知识图谱，支持158种编程语言，实现毫秒级查询并减少99%的Token消耗，极大提升AI编程助手的上下文效率。对于需要在大型代码库上运行AI代理的开发者而言，其单静态二进制、零依赖的部署方式以及超低延迟特性具有极高的实用价值。该项目处于AI编程工具与MCP生态的核心赛道，是当前IDE智能化与代码理解基础设施的重要组成部分。
#4 calesthio · AI视频智能体生产系统
OpenMontage 是全球首个开源的智能体视频制作系统，集成12条流水线、52个工具和500+智能体技能，能将AI编码助手转变为完整的视频制作工作室。该项目将Agentic AI与专业视频生产流程深度融合，大幅降低视频内容创作的技术门槛，适用于自动化影视制作、内容批量生成等场景。处于AI Agent与AIGC视频生成的交叉赛道，代表了下一代智能化内容生产工具的发展方向，极具关注价值。
#5 ai-berkshire · AI驱动价值投资研究
